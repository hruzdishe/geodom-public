# Локальные фотографии квартир

Импорт сопоставляет `media/apartments/<source>/<source_id>/<file>` с `(apartments.source, apartments.source_id)`.
Файлы загружаются в приватный MinIO bucket `geodom-seed-media`; PostgreSQL хранит связи, размеры, SHA-256, порядок и обложку. URL не сохраняется — существующий presenter генерирует presigned URL.

```bash
cd /home/naw/hakaton/geodom-backend
env -u DEBUG uv run python scripts/import_local_media.py
```

Повторный запуск не дублирует записи. Пользовательские объявления и их фото не изменяются. Импорт проверяет SHA-256 из имени файла и валидность изображения. Без исходного manifest порядок определяется именами файлов; первая фотография становится обложкой, уже существующие обложки сохраняются.

По умолчанию архивные фото имеют `publication_allowed=false` и `rights_status=not_verified_for_republication`, согласно исходному требованию проекта. Они связаны с квартирами, но публичный API их не показывает.

Только после явного разрешения на показ этих фотографий:

```bash
env -u DEBUG uv run python scripts/import_local_media.py --allow-publication
```

Этот запуск разрешает показ только сопоставленных локальных фото и фиксирует `rights_status=operator_authorized_for_publication`. Это отметка решения оператора, не утверждение об автоматически проверенной лицензии.

Текущий импорт: 1187 фотографий, 300 квартир, 300 обложек. 2026-09-27 пользователь явно разрешил показ этих фото; для них включена публикация. Повторный запуск проверен: новых дубликатов нет.
