# Проверка комплекта — 26 сентября 2026

Проверена именно папка `scoring` в Windows / Python 3.14.

- Чистое виртуальное окружение и установка `uv sync --locked`: успешно.
- Все 93 теста: успешно, в том числе в чистом окружении.
- `examples/backend_example.py`: оба скорера возвращают ожидаемые 50 баллов,
  район содержит одно подходящее синтетическое объявление.
- Все 9 установленных CLI-команд отвечают на `--help`.
- Обе JSON Schema совпадают с моделями Preferences и ScoringConfig.
- Ruff: ошибок нет.
- Все исходные Python-модули перенесены без изменения содержимого.

Для проверки не нужны выгрузки из прежней папки `ml`: тесты создают синтетические
данные во временных каталогах, а HTTP-ответы подменяются в тестах парсеров.
Тестовое окружение и результаты проверок находятся вне передаваемой папки.

Не проверялись: повторный сетевой сбор с источников, Linux, производительность
под нагрузкой, интеграция с конкретным API/БД бэкенда и качество рекомендаций
на пользовательской разметке. Проверка CLI `--help` не означает проверку
доступности внешних источников.

В комплект не входят собранные данные, фотографии, готовые географические слои,
вычисленные признаки, старые архивы, виртуальные окружения, кэши и `.env`.
