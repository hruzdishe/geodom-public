# Скоринг квартир

Реализация: `src/krasnoyarsk_ml/scoring.py`, версия `apartment_scoring_v1`.
Сначала применяются строгие фильтры цены, комнат, типа сделки и района.
Затем вычисляется персональный балл; цена сама по себе не даёт бонуса.

Для расстояния d и опорного расстояния r:

`s = 100 / (1 + (d / r)^2)`.

Для поддерживаемых активных критериев: `S = sum(w * s) / sum(w)`.
Вес w — целое 0–5. При неполных данных вес поддерживаемого критерия сохраняется
в знаменателе: пропуск не повышает рейтинг. Возвращаются покрытие и верхняя
граница возможной оценки; это не статистический доверительный интервал.
При полностью неизвестной оценке score равен null.

Школьник автоматически включает школы с весом 5, дошкольник — детсады с весом 5,
заданная работа — работу с весом 5. Ручное значение, включая 0, имеет приоритет.
Школы означают близость, не качество образования. Количества POI в радиусах
рассчитываются, но текущая формула использует ближайшие расстояния.

| Критерий | Расстояние для 50 баллов, м |
|---|---:|
| Школы | 500 |
| Детсады | 400 |
| Парки | 700 |
| Транспорт | 400 |
| Спорт | 1500 |
| Торговые центры | 2000 |
| Супермаркеты | 500 |
| Медицина | 1500 |
| Аптеки | 500 |

Настройки меняются через ScoringConfig. До работы используется геодезическое
расстояние по прямой. При заданной скорости v: `minutes = 60 * d / (1000 * v)`.
Без скорости минуты неизвестны. Если задано желаемое время, предупреждение
включается при `minutes > 1.15 * max_minutes`; квартира остаётся в выдаче.
Расчёт балла работы учитывает желаемое время и условную скорость, если они заданы;
иначе используется `work_half_score_distance_m` (по умолчанию 5000 м).

Экология, безопасность и кафе явно отмечаются как неподдерживаемые.
Интеграция, входные поля и примеры: [BACKEND.md](BACKEND.md).
